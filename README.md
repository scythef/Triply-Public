# Triply-Public

Public website for PupanCo. The existing repository name and GitHub Pages URLs
remain unchanged. The 1 November 2026 update changes the displayed app name only;
privacy terms, terms of use and support contacts are otherwise unchanged.

The privacy policy header uses `assets/PupanCo.png` as a responsive, uncropped
banner linking to the home page. The policy title and update date remain text
below the image for accessibility.
